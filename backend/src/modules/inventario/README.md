# Inventario MVC
Modelo: consultas SQL; servicio: validaciones; controlador: respuestas HTTP; rutas: endpoints.

GET /api/inventario, GET /api/inventario/:id, POST /api/inventario, PUT /api/inventario/:id, DELETE /api/inventario/:id.

**Nota:** API de ejemplo sin autenticación; no publicarla en Internet. Angular sigue usando datos de prototipo hasta conectar `inventario.api.service.ts`.
