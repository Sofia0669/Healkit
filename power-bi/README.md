# Dashboard de HealKit en Power BI

1. Desarrolla un informe en Power BI Desktop a partir de datos autorizados (preferentemente datos de prueba).
2. Guarda el archivo como `HealKit-Dashboard.pbix` en esta carpeta. El `.pbix` NO está incluido todavía.
3. Crea visuales de ventas, compras, inventario y finanzas, y conserva el modelo de datos para el análisis multidimensional que pide el profesor.
4. Si tienes un método autorizado para insertar el informe en Angular, configura la URL en `frontend/src/app/modules/dashboard/power-bi.config.ts`.
5. Para informes PRIVADOS, evalúa las opciones oficiales de inserción autenticada y sus requisitos de licenciamiento; no publiques datos privados con 'Publicar en la web'.

El prototipo muestra un área de espera; NO es un informe de Power BI real todavía.
